# HMI 函数注释 Doxygen 标签参考

## 标签说明

### @brief
- 必填标签
- 一句话描述函数功能
- 使用中文描述
- 放在函数注释的最前面

### @param
- 必填标签，每个参数一行
- 格式: `@param 参数名 参数说明`
- `void` 函数或无参函数可省略
- 设计指定参数时有特殊意义时也需要标记

### @return
- 必填标签
- 格式: `@return 返回值类型 返回值含义`
- `void` 函数写 `@return void`
- 返回指针时需说明指针生命周期

### @details
- 必填标签
- 详细描述函数的业务逻辑、执行流程和数据流向
- 可多行展开
- 建议包含:
  - 状态转换说明
  - 关键算法描述
  - 数据协议细节（如 CAN 帧格式）
  - 边界条件处理

### @note
- 必填标签
- 至少包含一条修改日期（精确到秒）
- 格式: `修改日期: YYYY-MM-DD HH:MM:SS`
- 可额外包含:
  - 调用时序约束
  - 调用频率说明
  - 前后依赖关系
  - 已知限制或问题

## 时间戳格式严格要求

```
修改日期: 2026-06-29 14:30:00
```

- 年份: 4位数字 (YYYY)
- 月份: 2位数字 (MM)
- 日期: 2位数字 (DD)
- 小时: 2位数字 24小时制 (HH)
- 分钟: 2位数字 (MM)
- 秒: 2位数字 (SS)
- 分隔符: `-` 连接日期，空格分隔日期和时间，`:` 连接时分秒

## 完整模板

```c
/**
 * @brief   [一句话功能描述]
 * @param   [参数名] [参数说明]
 * @param   [参数名] [参数说明]
 * @return  [返回值类型] [返回值说明]
 * @details [详细逻辑描述，可多行]
 *          [数据流向、协议格式、状态转换等]
 * @note    [注意事项]
 *          修改日期: YYYY-MM-DD HH:MM:SS
 */
```
